# La lista de IAs por tarea: la que se queda corta, la que cumple y la que usamos

Para cada trabajo del día a día, tres opciones y el motivo de cada una. Es una opinión, para que decidas tú. Si lo tuyo es crear contenido, mira también el capítulo «Las mejores IAs para crear contenido».

Revisada el 12 de noviembre de 2026.

---

## Para trabajar

| Para… | Se queda corta | Cumple | La que usamos |
|---|---|---|---|
| Buscar información | Google | ChatGPT | Perplexity |
| Programar | ChatGPT | Cursor | Claude Code |
| Tomar notas | Google Docs | Notion | Obsidian |
| Hacer presentaciones | PowerPoint | Google Slides | Claude |
| Crear imágenes | Meta AI | Midjourney | Nano Banana (Gemini) |

- **Buscar:** Perplexity te da la respuesta con las fuentes enlazadas, así que puedes comprobar cada dato. Google te da enlaces; ChatGPT te da una respuesta que no siempre cita de dónde sale.
- **Programar:** Claude Code trabaja dentro de tu proyecto: lee tus archivos, los cambia y prueba lo que hace. Cursor es un buen editor con IA; ChatGPT te obliga a copiar y pegar.
- **Notas:** Obsidian guarda tus notas como archivos en tu ordenador, y Claude puede leerlas para darte contexto. Notion es cómodo para equipos; un documento suelto no te deja conectar ideas.
- **Presentaciones:** Claude te hace el archivo de la presentación desde un texto o un documento, con su estructura. Revísala siempre antes de enseñarla.
- **Imágenes:** Nano Banana, dentro de Gemini, edita y mantiene a la misma persona o producto entre imágenes. Midjourney da imágenes muy bonitas; Meta AI sirve para jugar.

## Para montar una app sin saber programar

| Para… | Se queda corta | Cumple | La que usamos |
|---|---|---|---|
| Tener la idea | Gemini | ChatGPT | Claude |
| Escribir el código | Replit | Lovable | Claude Code |
| Guardar los datos | Google Sheets | Airtable | Supabase |
| Publicarla | WordPress | GitHub Pages | Vercel |

- **La idea:** pídele a Claude que te haga preguntas hasta que la idea esté clara antes de escribir nada (en el Manual tienes Grill Me para eso).
- **El código:** Lovable es lo más rápido para una primera versión; Claude Code, para seguir mejorándola sin depender de la plataforma.
- **Los datos:** una hoja de cálculo se queda corta en cuanto hay usuarios. Supabase es una base de datos de verdad, con un plan gratuito para empezar.
- **Publicar:** Vercel publica tu app desde GitHub y la actualiza cada vez que cambias algo.

## Lo que conviene saber

- Es nuestra opinión a fecha de hoy y estas herramientas cambian cada mes.
- Ninguna de estas marcas nos paga ni tiene relación con nosotros.
- Antes de subir datos de clientes a cualquier herramienta, mira dónde los guarda y qué permite tu ley de protección de datos.
