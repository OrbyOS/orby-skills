# Tres skills para que tu web no parezca hecha con IA

Las webs hechas con IA se parecen todas: mismos degradados, mismas tarjetas y las mismas frases. Estas tres skills gratuitas le dan a tu agente criterio de diseño. Entre las tres pasan de 280.000 estrellas en GitHub.

Revisada el 17 de noviembre de 2026.

---

## 1. Hallmark

Prohíbe los tics de diseño típicos de la IA, exige un mínimo de calidad (contraste, móvil, accesibilidad) y revisa la web en el navegador a ocho anchos. Licencia MIT.

`npx skills add nutlope/hallmark -g`

## 2. Impeccable

Le da a Claude el vocabulario de un diseñador: pulir, criticar, auditar, animar o simplificar una pantalla con órdenes concretas. Más de 110.000 estrellas.

Instalación y órdenes: github.com/pbakaus/impeccable

## 3. Taste

Dirección de arte para webs de empresa: textos claros, fotos reales, un sistema de diseño y una comprobación en el navegador antes de darte la web. Más de 115.000 estrellas.

Instalación: github.com/Leonxlnx/taste-skill

## Cómo usarlas

Instala una (o las tres) y pídele a Claude: «rediseña la portada de mi web con [nombre de la skill]». Para revisar una web que ya tienes: «haz una auditoría de diseño de esta página».

## Lo que conviene saber

- No hacen magia con un mal texto: primero, que la web diga claro qué vendes y a quién.
- Las comprobaciones en el navegador necesitan Chrome instalado.
