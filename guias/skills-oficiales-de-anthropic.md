# Las skills oficiales de Anthropic: Word, Excel, PowerPoint y PDF con Claude

Anthropic ha publicado en GitHub las skills con las que Claude crea y edita documentos: Word, Excel, PowerPoint y PDF. Son las mismas que usa Claude por dentro. El repositorio tiene casi 200.000 estrellas.

Revisada el 18 de noviembre de 2026.

---

## Qué trae

- **Documentos:** las skills docx, xlsx, pptx y pdf, de código abierto (licencia Apache 2.0).
- **Ejemplos:** skills de diseño, de pruebas de webs, de comunicación y de marca, para aprender cómo se hacen.
- **Una plantilla** para crear tus propias skills: una carpeta con un archivo SKILL.md que explica a Claude qué hacer.

## Cómo instalarlas

En Claude Code:

`/plugin marketplace add anthropics/skills`

y después:

`/plugin install document-skills@anthropic-agent-skills`

Para los ejemplos: `/plugin install example-skills@anthropic-agent-skills`

En la aplicación de Claude, las skills de ejemplo están disponibles en los planes de pago.

## Lo que conviene saber

- Anthropic las publica como ejemplo y para aprender: pruébalas antes de usarlas en algo importante.
- Algunas skills de ejemplo pueden tener otra licencia; míralo en el repositorio.
