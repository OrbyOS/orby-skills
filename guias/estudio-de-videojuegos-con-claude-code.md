# Claude Code Game Studios: describe un juego y te lo construye

Una plantilla gratuita que convierte Claude Code en un estudio de videojuegos con 49 agentes: dirección, diseño, programación, arte, sonido, guion y pruebas. Describes el juego, te hace unas preguntas, escribe una ficha de una página y construye un juego que ya se puede jugar en el navegador.

Revisada el 13 de noviembre de 2026.

---

## Qué necesitas

- Claude Code, Git, Python 3 y Bash (en Windows, Git para Windows).
- Chrome, Edge o Chromium para que pruebe el juego solo.

## Cómo empezar

```
git clone https://github.com/Donchitos/Claude-Code-Game-Studios.git mi-juego
cd mi-juego
claude
```

Dentro de Claude Code:

- `/prototype un juego de pesca donde los peces raros solo pican al atardecer` para empezar un juego.
- `/start` si quieres que te guíe.
- `/next-step` o `/brainstorm` para seguir.

Abre Claude Code en la carpeta principal del proyecto, no en una subcarpeta.

## Lo que conviene saber

- Lo más probado es el juego de navegador. Godot, Unity y Unreal funcionan, pero están menos probados.
- El modo ligero (el que viene por defecto) dio mejores juegos que el modo con 30 documentos previos.
- Los juegos se prueban solos con capturas, pero juégalo tú antes de enseñarlo.
- Gratis y de código abierto (MIT).
