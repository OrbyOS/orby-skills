# T3 Code: Claude Code desde el móvil

T3 Code es una aplicación gratuita y de código abierto (licencia MIT) para manejar Claude Code, Codex, Cursor y otros agentes desde el ordenador, el navegador o el móvil. Tiene más de 63.000 estrellas en GitHub.

Revisada el 17 de noviembre de 2026.

---

## Qué hace

- **Empiezas en el ordenador y sigues en el móvil:** mandas una tarea y apruebas el siguiente paso desde donde estés.
- **Todos tus agentes en una pantalla:** Claude Code, Codex, Cursor, OpenCode y otros.
- **Cambias de modelo** a mitad de conversación o pasas el trabajo de un agente a otro.
- **No revende nada:** usa las cuentas y suscripciones que ya tienes.

## Cómo instalarlo

1. Ten instalado y con la sesión iniciada al menos un agente, por ejemplo Claude Code (`claude auth login`).
2. Descarga la aplicación de escritorio en t3.codes (macOS, Windows o Linux), o pruébala con `npx t3@latest`.
3. Instala la app en el móvil (App Store o Google Play) y sigue la guía de acceso remoto para conectarla con tu ordenador.

## Lo que conviene saber

- Los agentes trabajan en tu ordenador: tiene que estar encendido y conectado.
- Para usarlo fuera de casa hay que configurar el acceso remoto (red local, Tailscale o su servicio T3 Connect).
